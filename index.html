Good to know

Quick answers.

Which download should I choose?

Choose Installer for the standard Windows setup, Start Menu entry, and optional desktop shortcut. Choose Portable if you would rather run the app directly without a standard installation.

Does HF STUDIO include AI?

HF STUDIO connects to Ollama, which runs AI locally on your computer. If Ollama is not installed, the app guides you through its installer. You separately approve any model download.

Will it send emails without my approval?

No. You review the message and explicitly confirm each email before it is sent. Business listings can be incomplete, so verify the business and its contact details first.

Why does Windows show a security warning?

This release is not code-signed, so Windows may show a SmartScreen warning. Download only from a source you trust and verify the file against the published SHA-256 checksums if needed.
